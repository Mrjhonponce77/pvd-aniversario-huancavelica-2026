Formato deportivo claro para una jornada ágil

Reglamento

Reglas rápidas y criterios deportivos

Resumen operativo para participantes y organizadores durante el campeonato de fulbito aniversario.

01

Puntaje

Partido ganado
3 pts
Partido empatado
1 pt
Partido perdido
0 pts
02

Clasificación

Clasifican los dos mejores equipos de cada grupo. Las semifinales se cruzan entre primeros y segundos de grupos opuestos.

03

Estados de partido

  • Programado: partido pendiente.
  • En vivo: partido en desarrollo.
  • Finalizado: marcador confirmado.
  • Suspendido: partido detenido o reprogramado.
  • W.O.: definido por ausencia de un equipo.
04

Criterios de desempate

  1. Mayor puntaje.
  2. Mejor diferencia de goles.
  3. Mayor cantidad de goles a favor.
  4. Resultado directo entre equipos empatados.
  5. Menor cantidad de sanciones, si se registra.
  6. Decisión del comité organizador.
